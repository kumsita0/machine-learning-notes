# Neural Networks

## What is a Neural Network?

A Neural Network is a machine learning model inspired
by the way biological neurons process information.

It contains connected layers of artificial neurons
that learn patterns from data.

## Key Concepts

- Neuron — basic processing unit
- Weight — controls the importance of an input
- Bias — helps adjust the output
- Layer — group of neurons
- Input Layer — receives the input
- Hidden Layer — learns patterns
- Output Layer — produces the prediction

## Example

For image classification:

- Input → Image of an animal
- Hidden Layers → Learn shapes and patterns
- Output → Cat: 90%, Dog: 10%

The model predicts that the image is probably a cat.

## My Takeaway

Neural networks learn complex patterns by processing
information through connected layers of neurons.
